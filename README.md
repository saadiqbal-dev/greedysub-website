# GreedySub website

The public website for GreedySub, a free, open-source, local-first Chrome extension for tracking subscriptions and free trials.

## Development

Requirements: Node.js 20 or newer and npm.

```bash
npm install
npm run dev
```

Open the local URL printed by Vite. Before submitting changes, run:

```bash
npm run check
```

## Project structure

- `src/components` contains the landing-page sections.
- `src/pages` contains the Terms and Privacy routes.
- `public` contains static assets and the web manifest.
- `tests` checks public messaging and structured metadata.
